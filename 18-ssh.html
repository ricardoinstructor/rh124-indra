Contraseña frente a clave pública

CriterioContraseñaClave pública
Dónde se guardaSu hash en /etc/shadow, en el servidorPrivada en el cliente (~/.ssh/id_ed25519), pública en authorized_keys
Qué viaja por la redLa contraseña, protegida por el canal cifradoSolo la firma; la clave privada no viaja
Revocaciónpasswd usuario cambia el secretoBorrar la línea correspondiente en authorized_keys
AutomatizaciónExige introducir el secreto en cada sesiónPermite scripts de ssh sin interacción

Endurecimiento de /etc/ssh/sshd_config

DirectivaEfecto
PasswordAuthentication noProhíbe el acceso con contraseña
PermitRootLogin prohibit-passwordroot solo entra con clave
PubkeyAuthentication yesPermite el acceso con clave pública

Tras editar el fichero: sudo sshd -t valida la sintaxis y sudo systemctl reload sshd aplica los cambios sin cortar las sesiones abiertas.

Chuleta de comandos

ssh-keygen -t ed25519 # crea el par de claves en el cliente ssh-copy-id student@servera # instala la clave pública en el servidor ssh -i ~/.ssh/id_ed25519 student@servera # usa una clave concreta ssh -p 2222 student@servera # puerto alternativo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub # huella del host sudo sshd -t # valida la sintaxis de sshd_config sudo journalctl -u sshd -b --no-pager # accesos registrados desde el arranque
