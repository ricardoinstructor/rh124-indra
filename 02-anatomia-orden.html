Anatomía de una orden

Estructura de la línea de órdenes cada elemento tiene un color y una función

Etiquetado de una orden real elija una orden

prompt
usuario@host:directorio$
comando
programa ejecutado
opciones
modifican el comportamiento
argumentos
objetos de la operación

Chuleta de comandos cada línea, un elemento de la estructura

ls # solo el comando: lista el directorio actual ls -l # opción corta: listado detallado ls --long # opción larga equivalente a -l ls -l /etc/passwd # argumento: un archivo concreto dnf install vim # subcomando como argumento del comando dnf man ls # documentación de la orden: secciones DESCRIPCIÓN y OPCIONES
