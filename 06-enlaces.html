06 · UNIDAD 7

Enlaces duros y simbólicos

Lectura del diagrama fichero original con su inodo, duro al mismo inodo, simbólico a una ruta

El original existe: ambos enlaces funcionan.

Comparativa

AspectoEnlace duroEnlace simbólico
Qué guardaEl número de inodo, compartidoLa ruta hacia el destino
Al borrar el originalLos datos sobreviven mientras exista el enlaceEl enlace queda roto y no abre nada
Sistemas de archivosSolo dentro del mismo sistema de archivosPuede apuntar a cualquier ruta accesible
PermisosComparte los permisos del inodo originalTiene permisos propios; los del destino siguen aplicando

Chuleta de comandos

ln /var/lib/datos.txt /tmp/hard.txt # enlace duro ln -s /var/lib/datos.txt /tmp/soft.txt # enlace simbólico ls -li /var/lib/datos.txt /tmp/*.txt # -i muestra el inodo stat /tmp/soft.txt # el tamaño es la ruta rm /var/lib/datos.txt # el duro sigue, el simbólico no readlink /tmp/soft.txt # muestra la ruta guardada
