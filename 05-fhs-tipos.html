Jerarquía FHS y tipos de fichero

Árbol de directorios FHS: Filesystem Hierarchy Standard

Lectura de arriba abajo: de / cuelgan catorce ramas de uso general. Cada rama agrupa ficheros con la misma función. /proc y /sys son virtuales (las crea el núcleo); /afs es el punto de montaje del sistema de archivos de red AFS.

Tipos de fichero según ls -l primer carácter de la línea

CarácterTipoFunción
-Fichero regularContiene datos: texto, binario o imagen.
dDirectorioAgrupa entradas con nombre y contiene otros ficheros.
lEnlace simbólicoGuarda una ruta hacia otro fichero del sistema.
bDispositivo de bloquesAcceso por bloques a discos, SSD o particiones.
cDispositivo de caracteresAcceso byte a byte: teclado, terminal, puertos.
sSocketPunto de comunicación local entre dos procesos.
pTubería con nombreArchivo especial que conecta procesos del mismo host.

El enlace duro aparece en la misma columna que el fichero regular: ls -l no lo distingue; solo lo delata el número de inodo repetido.

Chuleta de comandos

ls -l /etc # primer carácter = tipo de cada entrada ls -F /usr/bin # añade / * @ = a cada nombre file /dev/sda # contenido real del fichero stat /etc/hostname # tipo, inodo y permisos tree -d /etc # solo directorios, en jerarquía cd /var/log # los registros del sistema ls /opt /srv # software opcional y datos servidos ls /sys/class/net # interfaces vistas por el núcleo
