Del código abierto a RHEL

Flujo de izquierda a derecha qué hereda cada proyecto del anterior

Flechas rojas: herencia de código. Flechas verdes: dependencia de soporte.

Qué aporta cada capa

CapaQué significa
Código abiertoSoftware distribuido con una licencia que permite usarlo, estudiarlo y redistribuirlo.
Linux genéricoNúcleo más utilidades de espacio de usuario, sin identidad de fabricante.
FedoraProyecto patrocinado por Red Hat: integra y prueba tecnologías antes de su llegada a RHEL.
CentOS StreamVersión estable que sigue a Fedora de forma continua y anticipa cada publicación de RHEL.
RHELDistribución reconstruida con suscripción, ciclo de vida soportado y casos de soporte.
OpenShiftPlataforma de contenedores que usa RHEL como sistema base certificado.

Chuleta de comandos versión y distribución instaladas

cat /etc/redhat-release # versión de RHEL instalada rpm -E %rhel # versión principal del producto hostnamectl # sistema operativo y núcleo activos uname -r # versión del núcleo Linux en ejecución dnf info redhat-release # paquete que declara la versión dnf repolist # repositorios habilitados
