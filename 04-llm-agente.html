LLM y modo agéntico

LLM frente a agente qué aporta cada uno en la administración del sistema

Un LLM aislado no toca el sistema: el agente añade herramientas, entorno y ciclo de retroalimentación.

Qué significa y qué riesgo tiene

ConceptoQué significa
LLMModelo entrenado que estima el texto más probable a partir del contexto recibido; su salida es texto.
No ejecutaSin herramientas, el modelo no lanza órdenes ni lee archivos: solo propone texto que el usuario copia.
HerramientasInterfaces controladas que conectan el modelo con dnf, systemctl o la lectura de archivos.
Modo agénticoCiclo de pasos: proponer, ejecutar, leer el resultado real y volver a decidir con esa información.
Asistente de RHELAñade el contexto del sistema y la confirmación del usuario antes de ejecutar cada orden.
RiesgoVerificar siempre la orden propuesta antes de confirmarla y no enviar datos sensibles del sistema a servicios externos.

Ejemplo con dnf el asistente propone, el usuario confirma

# 1. Objetivo del usuario: comprobar el estado del paquete vim dnf info vim # el asistente propone esta orden de solo lectura # 2. El usuario revisa la orden y la confirma; la salida real vuelve al modelo # 3. Solo entonces el asistente propone la orden de cambio dnf install vim # requiere confirmación explícita antes de ejecutarse # 4. Verificación posterior con una orden real del sistema rpm -q vim # consulta la versión instalada del paquete
