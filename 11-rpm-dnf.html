RPM, DNF y resolución de dependencias

El flujo del paquete el repo entrega, dnf resuelve, rpm instala

rpm -i miapp.rpm falla si falta libfoo; dnf install miapp la trae del repo.

DNF frente a RPM uno resuelve, el otro instala

CriterioDNFRPM
Lee el repoSí: metadatos y .rpm de BaseOS y AppStreamNo: solo el paquete que se le entrega
DependenciasLas resuelve y descarga lo que faltaFalla si falta una dependencia
InstalaDelega en rpm, paquete a paqueteInstala, actualiza y verifica cada .rpm

Chuleta de comandos

dnf install vim-enhanced # instala y resuelve dependencias dnf repoquery --requires vim-enhanced # dependencias del paquete dnf repoquery --requires --resolve vim-enhanced # dependencias ya resueltas rpm -q --whatprovides /usr/bin/vim # qué paquete trae ese fichero rpm -q --whatrequires glibc # quién depende de glibc rpm -ql vim-enhanced # ficheros instalados rpm -V vim-enhanced # verifica la integridad del paquete dnf history info last # última transacción realizada
