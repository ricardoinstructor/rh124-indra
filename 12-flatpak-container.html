Flatpak frente a contenedores

Dos carriles de aislamiento Flatpak trae la app con su runtime; podman trae la imagen con su servicio

Comparativa cinco criterios

CriterioFlatpakContenedor
ContenidoAplicación y sus datos, sobre un runtime compartido del sistemaServicio completo con librerías propias dentro de la imagen
AislamientoSandbox de usuario (bubblewrap), permisos declarativos y portalsNamespaces del kernel: mount, pid, net, user, uts
GranularidadUna aplicación de escritorio concretaUn servicio completo con su proceso y configuración
Uso típicoEntorno de escritorio: editores, navegadores, juegosServidores: bases de datos, API, microservicios
Herramientasflatpak, remotos, flatpak overridepodman, buildah, imágenes OCI

Chuleta de comandos

flatpak remotes # remotos configurados (flathub) flatpak remote-add --if-not-exists flathub \ # añade el remoto Flathub https://flathub.org/repo/flathub.flatpakrepo flatpak install flathub org.gimp.GIMP # instala aplicación + runtime flatpak list # aplicaciones instaladas flatpak run org.gimp.GIMP # ejecuta la aplicación aislada flatpak override --user --filesystem=host \ # amplia permisos declarativos org.gimp.GIMP podman run -p 8080:80 --rm nombre-imagen # puerto publicado y borrado al salir
