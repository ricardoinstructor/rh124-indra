Calculadora de permisos: simbólico, octal y especiales

Activa los bits y observa las tres notaciones rwx · 0640 · 4750

Dueña (u)
Grupo (g)
Otros (o)

SUID en ejecutables, SGID en directorios y sticky en carpetas compartidas. Ninguno de los tres cambia el significado de r, w ni x.

BitValor
r4
w2
x1
s (SUID)4
s (SGID)2
t (sticky)1

umask y casos típicos máscara que el shell resta a 666

umaskEquivale aArchivos nuevosDirectorios nuevos
0220644 / 0755666 - 022 = 644777 - 022 = 755
0770600 / 0700666 - 077 = 600777 - 077 = 700

Un archivo no tiene permiso de ejecución por defecto: el bit x se activa de forma explícita con chmod +x.

chmodSimbólicoUso
0700rwx------Privado del dueño, script personal.
0750rwxr-x---Directorio de equipo, el grupo entra.
0755rwxr-xr-xEjecutable público, repositorio web.
4750rwsr-x---SUID en el ejecutable, uso administrativo puntual.
2775rwxrwsr-xSGID en el directorio: el grupo hereda el dueño.
1777rwxrwxrwtSticky en carpeta compartida, como /tmp.

Chuleta de comandos

ls -l /etc/shadow # -rw-r----- 1 root root stat -c '%A %a %U %G' /etc/passwd # simbólica, octal, dueño, grupo chmod 0640 informe.txt # forma octal de 4 digitos chmod u=rw,go=r informe.txt # forma simbólica chmod 4750 programa.sh # añade SUID a un ejecutable chmod u+s,g-s,o=t /tmp/compartido # bits especiales umask 077 # archivos 600 y carpetas 700
